# ShopHub — Interactive Product Page

A sleek, modern e-commerce product page built with **HTML, CSS, and JavaScript**.  
It features a dynamic image gallery, size/color selectors, quantity control, and a fully interactive shopping cart sidebar — all in a clean, responsive layout.

🔗 **Live Demo:** [ShopHub on GitHub Pages](https://bigrobzin.github.io/Shop-hub/)


## Features

- **Interactive Image Gallery** — Click thumbnails to view different product angles  
- **Dynamic Options** — Select size and color variations  
- **Quantity Selector** — Adjust purchase quantity before adding to cart  
- **Cart Sidebar** — Add, remove, and update items in a slide-out cart  
- **Live Total Calculation** — Automatically updates cart total  
- **Responsive Design** — Looks great on both desktop and mobile devices  
- **Smooth UI Effects** — CSS transitions and hover animations for modern feel  


## Tech Stack

- **HTML5** — Structure and semantics  
- **CSS3** — Styling and responsive layout  
- **JavaScript (Vanilla)** — DOM manipulation and cart logic

How It Works;

Clicking a thumbnail swaps the main product image.

Selecting a size or color updates internal state for the cart item.

The Add to Cart button adds the configured product to the cart array and updates the count.

The Cart Sidebar slides in/out and dynamically displays items, quantities, and total cost.

You can remove items or change quantities directly in the cart.
